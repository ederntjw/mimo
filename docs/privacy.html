Privacy Policy

Last updated: September 10, 2026

Mimo is local-first. By default, speech-to-text processing runs on your Mac and audio stays on your device. If you explicitly select an optional hosted dictation provider, Mimo sends that dictation audio to OpenAI or through OpenRouter to your selected upstream model for transcription. Optional hosted reasoning and account sync use the services described below.

What Mimo Does

Mimo is a macOS application for dictation and meeting transcription. It uses on-device machine learning models (CoreML / Apple Neural Engine) to convert speech to text entirely on your Mac by default. Optional OpenAI and OpenRouter dictation providers are available only when you choose and configure them.

Data That Stays on Your Device

The following data is created and stored locally on your Mac. It is not transmitted to any external server unless you explicitly enable an optional cloud service described below:

  • Audio recordings — microphone and system audio captured during dictation and meetings; dictation audio is sent to a hosted service only while you have explicitly selected OpenAI or OpenRouter as the dictation provider
  • Transcripts and meeting notes — stored in a local SQLite database
  • Configuration and preferences — stored in a local JSON file
  • Speech-to-text models — downloaded once from public model repositories (HuggingFace) and cached locally

Optional Cloud Services

Mimo offers optional integrations that connect to external services. These are opt-in and require explicit user action:

  • OpenAI dictation (OpenAI API) — if you select OpenAI as your dictation provider and add your own API key, microphone audio is streamed directly to OpenAI's Realtime transcription API. OpenAI's API data controls explain how API data is used, retained, and excluded from model training by default; see OpenAI's API data-controls documentation for the current retention and data-sharing settings.
  • OpenRouter dictation — if you select OpenRouter as your dictation provider, connect an account or key, and choose a transcription model, the completed dictation recording is sent through OpenRouter to that selected upstream model. Processing is governed by OpenRouter's and the selected model provider's policies.
  • Meeting summarization (OpenAI API / OpenRouter) — if configured, meeting transcripts are sent to the selected API provider to generate summaries. This is governed by the respective provider's privacy policy.
  • Meeting summaries and questions (ChatGPT sign-in) — if you sign in with your ChatGPT account and select it as the reasoning provider, relevant transcripts and review excerpts are sent to OpenAI's ChatGPT/Codex service using models available to that account.
  • Mimo Account sync — when available in the build and enabled by signing in, dictation text, meeting transcripts, summaries, manual notes, titles, and related text metadata are sent to the configured Mimo account service to sync across your devices. Audio files, downloaded models, provider credentials, and ChatGPT or Google sign-in tokens are excluded from this sync. Builds without the account service configured keep the library on the Mac.
  • Sparkle update checks — Mimo checks for new versions via an appcast feed hosted on GitHub. No personal data is transmitted.

Google Calendar Integration

Mimo can optionally connect to your Google Calendar to display upcoming meetings in the status bar and auto-detect meeting start times. When you connect Google Calendar:

  • Mimo requests read-only access to your calendar events (event titles, times, and durations)
  • Calendar data is fetched directly from Google's API to your Mac — it does not pass through any intermediary server
  • Calendar events are used to display upcoming meetings and associate recordings with events; an event title and reference attached to a meeting can remain in that meeting's local metadata
  • Google OAuth tokens are stored in permission-restricted local files and marked for exclusion from backups
  • You can revoke access at any time from your Google Account permissions page

macOS Permissions

Mimo requests the following macOS permissions, each for a specific purpose:

  • Microphone — to capture your voice for dictation and meeting transcription
  • System Audio Recording — to capture the other side of online meetings; the permission name can include Screen Recording on some macOS versions
  • Accessibility — to paste transcribed text into other applications
  • Input Monitoring — to detect the global dictation hotkey
  • Calendar — to read upcoming events from your local macOS calendar (EventKit)

Anonymous Usage Analytics

Mimo uses TelemetryDeck to collect minimal, anonymized usage signals (e.g., which features are used and app launch counts). When Mimo detects a hard failure, it may also send an allowlisted diagnostic category, workflow stage, selected on-device transcription backend/model, app version and build, operating system and device model, and a random incident ID. These diagnostics never include raw error messages, audio, transcripts, meeting or calendar titles, clipboard or screen contents, API keys, auth tokens, local file paths, raw logs, database contents, or other personal content. TelemetryDeck does not store IP addresses, and identifiers used for anonymous user and session counts cannot be traced back to a person. You can learn more about TelemetryDeck's privacy practices on their privacy page.

Local Storage and Optional Sharing

Meeting content remains local unless you choose a cloud feature described above, such as hosted transcription, hosted reasoning, or Mimo Account sync. Mimo Account sessions use macOS Keychain. ChatGPT and Google session tokens use permission-restricted local files marked for exclusion from backups. These credentials are not part of account sync. Local features work without an internet connection after their models are downloaded; cloud features require a connection.

Reviewed meetings hold temporary microphone and system-audio files for the after-meeting transcription. These temporary files are removed after processing or cancellation. The separate recording-save preference controls whether Mimo retains an audio recording in your meeting library.

Open Source

Mimo's source code is publicly available on GitHub under the MIT license. You can inspect exactly what the application does with your data.

Children's Privacy

Mimo is not directed at children under 13. We do not knowingly collect data from children.

Changes to This Policy

If this policy changes, the updated version will be posted here with a revised date. Mimo does not have a mechanism to notify users of policy changes since we do not collect contact information.

Contact

For questions about this privacy policy, open an issue on GitHub or reach out to the maintainer via the repository.
