## Mimo 0.8.6

Mimo now treats live conversations, lectures, local cleanup, and cross-device accounts as one coherent workflow.

### Live Meeting and Lecture

- Meetings now start from a prominent, balanced launcher and open directly to Live Summary.
- Lecture mode uses a separate study-oriented note structure for concepts, examples, key terms, unclear points, and review tasks.
- The first rolling brief is eligible after roughly 10–15 seconds of committed speech, then refreshes about every 30 seconds.
- Ask Mimo uses GPT-5.4 Mini through ChatGPT sign-in while recording and local transcription continue uninterrupted.
- Parakeet and Apple Speech remain the local transcription choices.

### Mimo Account sync

- Optional Mimo-owned accounts sync transcripts, manual notes, summaries, and text metadata across Mac, iPhone, and future Android clients.
- The local SQLite library remains fully usable offline and keeps its dirty outbox and transactional cursor protections.
- Audio, downloaded models, API credentials, screen context, and secrets remain on each device.
- Existing legacy iCloud users retain a migration path, while the main dashboard now leads with Mimo Account sync.

### Local cleanup and Quill

- Every build includes Mimo Tiny Cleanup, a checksum-pinned SmolLM2 360M quantization for fast transcript cleanup on M1-class Macs without an account or network connection.
- Speech transcription remains handled by Parakeet or Apple Speech; the bundled model only cleans completed transcript text.
- Quill has its own visible provider and model controls, clearer target guidance, and keeps general-purpose local models separate from the tiny cleanup model.
- The dictation indicator follows the active text caret instead of appearing at an unrelated floating position.

### Strawberry Milk polish

- Strawberry Milk now covers the Live Meeting, Lecture, Live Summary, Ask Mimo, controls, cards, navigation, settings, and menu surfaces.
- Selecting the theme immediately switches the in-app and running application icon to the matching pink waveform artwork.
- Classic remains the default and Strawberry Milk still initially selects the Pink accent without locking later accent changes.

### Reliability and distribution

- Discard confirmation is deferred safely outside SwiftUI's layout transaction on macOS 26.
- Preview DMGs now ad-hoc sign the complete app bundle consistently, while public releases fail closed unless Developer ID signing and Apple notarization succeed for both the app and DMG.
- Sparkle continues to provide signed in-app update checks and one-click installation from GitHub Releases.
