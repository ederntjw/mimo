## Mimo 0.8.6

Mimo supports Chinese–English meetings with English notes, improves recording controls, and makes the desktop app easier to reopen and quit.

### Live Meeting and Lecture

- Reviewed meetings now use SenseVoice Small for fast Mandarin–English live text, then the selected full Whisper Large v3 or Turbo model for the complete recording after Stop. A comparison of the live and final transcripts informs the English minutes and surfaces unresolved details.
- Settings distinguish the live and after-meeting models, show required downloads, and keep a meeting's choices stable from recording through review. Full Whisper Large v3 has its own download, language, and hardware guidance.
- Meetings now start from a prominent, balanced launcher and open directly to Live Summary.
- Lecture mode uses a separate study-oriented note structure for concepts, examples, key terms, unclear points, and review tasks.
- The first rolling brief is eligible after roughly 10–15 seconds of committed speech, then refreshes about every 30 seconds.
- ChatGPT summaries and Ask Mimo use models available to the signed-in Codex account. Automatic prefers a fast model; explicit model choices apply to the next request. Unsupported older Mini settings recover automatically.
- Chinese–English meeting mode supports SenseVoice and multilingual Whisper to preserve code-switching, while summaries, titles, action items, and live answers are presented in English.
- SenseVoice Small is recommended for fast bilingual meetings; Whisper Large v3 Turbo remains available when accuracy matters more. Dictation keeps its own model selection. Language preferences shared with meetings are locked while recording.
- SenseVoice processes long recordings in complete, consecutive windows, preserving audio beyond its encoder limit.
- Model descriptions and language coverage have been corrected, with FluidAudio updated to 0.15.6.
- Model details now distinguish supported languages, tested Mandarin–English mixing, automatic detection, and one-language sessions. New recommendations exclude older and experimental speech models while preserving existing selections and downloads.
- The model library detects the Mac's chip, RAM, and free disk locally, then shows model strengths, separate download and memory estimates, and hardware suitability. Local AI options explain their cleanup or rewriting role.
- Live captions can use the meeting transcript model without an extra preview. Preview and language controls explain when a change must wait until the next meeting.

### Mimo Account sync

- Optional Mimo-owned accounts sync transcripts, manual notes, summaries, and text metadata across Mac, iPhone, and future Android clients.
- Builds without an account-sync service keep the library on the Mac; ChatGPT sign-in for summaries remains a separate option.
- The local SQLite library remains fully usable offline and keeps its dirty outbox and transactional cursor protections.
- Audio, downloaded models, API credentials, screen context, and secrets remain on each device.
- Existing legacy iCloud users retain a migration path, while the main dashboard now leads with Mimo Account sync.

### Local cleanup and Quill

- Every build includes Mimo Tiny Cleanup, a checksum-pinned SmolLM2 360M quantization for fast transcript cleanup on M1-class Macs without an account or network connection.
- The bundled cleanup model works on completed transcript text; speech recognition uses the selected transcription model.
- Quill has its own visible provider and model controls, clearer target guidance, and keeps general-purpose local models separate from the tiny cleanup model.
- The dictation indicator appears above the active text field, with a screen-edge fallback that keeps the input visible.

### Strawberry Milk polish

- Strawberry Milk now covers the Live Meeting, Lecture, Live Summary, Ask Mimo, controls, cards, navigation, settings, and menu surfaces.
- Selecting the theme immediately switches the in-app and running application icon to the matching pink waveform artwork.
- Classic remains the default and Strawberry Milk still initially selects the Pink accent without locking later accent changes.

### Reliability and distribution

- Removed word-count and meeting milestone popups, contribution requests, and sidebar social promotions.
- Sign-in confirmations, model download messages, Shortcuts, activity exports, and public pages use Mimo branding.
- Discard confirmation is deferred safely outside SwiftUI's layout transaction on macOS 26.
- The live recording floater can be dragged while its transcript is expanded, keeps its saved position, and preserves pause and stop controls.
- Transcribing, cleaning, and summarizing stay at the same saved pill position and remain draggable. Dictation does not overwrite that meeting position.
- Whisper and Parakeet model selections now reach the actual inference engine, including when a different model was preloaded in the background. Switching to SenseVoice, Qwen3, or Parakeet Unified waits for the selected model to finish loading.
- SenseVoice bilingual meetings commit short chunks about every three seconds or at natural pauses. Whisper keeps more context, with optional fast provisional captions. Changing the meeting model immediately adjusts chunk timing.
- Opening an already-running Mimo restores its window. Closing the dashboard keeps Mimo accessible in the Dock and Force Quit.
- Approved quit no longer waits indefinitely for background cleanup; active meeting confirmation remains in place.
- Public downloads require Developer ID signing, Apple notarization, and attached approval tickets for both the app and DMG. Uploaded release files are verified before a draft becomes public.
- Local replacements preserve the existing Developer ID identity, settings, meetings, and downloaded models.
- Sparkle continues to provide signed in-app update checks and one-click installation from GitHub Releases.
